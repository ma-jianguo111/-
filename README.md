# 超哥消消小 · C 语言课程设计

用 C 语言从零实现的三消（Match-3）游戏，命令行界面，**单文件、零第三方依赖**。

> 提交说明：本仓库的主体是 `match3.c`（C 源码）与 `课程设计说明.md`（设计文档）。
> `web/` 目录是后来用 JavaScript 复刻的试玩版，与本次 C 语言课程设计无关。



## 一、编译与运行

```
编译：  gcc match3.c -o 超哥消消小.exe
        tcc match3.c -o 超哥消消小.exe

运行：  超哥消消小.exe
```

也可用 Dev-C++ / Visual Studio / Code::Blocks 直接打开 `match3.c` 编译运行。

**运行环境**：Windows 10 / 11 控制台程序。启动时程序会自动把控制台切到 UTF-8 代码页并开启 ANSI 转义，否则中文与颜色会乱码。

**操作**：方向键移动光标 · 空格选中/交换 · `h` 提示 · `r` 重开 · `q` 退出

## 二、功能概览

- **28 关**，8×8 棋盘，6 种动物
- 交换相邻棋子，三个以上同类连成线即消除，上方棋子下落补位，可连锁
- 过关按剩余步数评五档星级，每剩 1 步折算 100 分

### 特殊棋子

| 棋子 | 生成条件 | 效果 |
| --- | --- | --- |
| 直线光（横）`=` | 横向四连 | 清掉整行 |
| 直线光（竖）`\|` | 纵向四连 | 清掉整列 |
| 炸弹 `*` | L 形 / T 形五连 | 清掉周围 3×3 |
| 彩虹 `@` | 五连一线 | 与任意棋子交换，清除全场同类 |

两种特殊棋子互相交换会触发强化组合。

### 障碍与棋盘机制

| 标记 | 名称 | 规则 |
| --- | --- | --- |
| `[ ]` | 冰块 | 需消除两次，第一次只破一层 |
| `~` | 油污 | 被油污粘住的格子不能交换，必须先消掉它上面的棋子；每两步向外扩散一格 |
| `( )` | 传送门 | 成对出现，棋子落进一扇会从另一扇出来，可远程凑消除 |
| 数字 | 定时炸弹 | 角标是剩余步数，8 步内不消除就爆炸，格子变油污并扣 3 步 |

### 关卡目标（一关可要求 2~3 项，全部达成才算过关）

分数 / 收集指定动物 / 清冰块 / 达成连锁 / 制造特效 / 清除油污 / 拆除炸弹

### 自检命令

```
超哥消消小.exe --rule         规则断言测试
超哥消消小.exe --test         28 关自动对局，输出通过率
超哥消消小.exe --grind 2 60   反复压测第 2 关 60 局
超哥消消小.exe --demo         只渲染一帧，检查排版
```

详细的设计思路与算法说明见 [`课程设计说明.md`](课程设计说明.md)。
