同一个三消游戏的两个版本：**Windows 控制台版（C）** 和 **网页版（单文件 HTML）**。

---

## 版本一：C 语言版（控制台）

跑在 Windows 控制台里的三消小游戏，单文件实现，不依赖第三方库。

> 注：C 版停留在较早的关卡规则（单目标、无星星与箱子），网页版是后续持续迭代的版本。

```
编译： tcc match3.c -o 动物消消乐.exe
       gcc match3.c -o 动物消消乐.exe
运行： 动物消消乐.exe
```

## 玩法

8×8 棋盘，点选或方向键移动光标，交换相邻动物，三只以上连成线即消除，上方掉落补充，可连锁。

| 操作 | 键位 |
| --- | --- |
| 移动光标 | 方向键 |
| 选中 / 交换 | 空格 |
| 提示 | h |
| 重开本关 | r |
| 退出 | q |

## 规则

- **三连及以上**消除，连锁倍率依次为 1 / 1.5 / 2 / 2.5 / 3 / 4 / 5 / 6 / 8
- **横向四连** → `=` 直线光，清掉整行
- **纵向四连** → `|` 直线光，清掉整列
- **L 形或 T 形五连** → `*` 炸弹，只炸自身周围 3×3
- **五连一线** → `@` 彩虹
  - 配任意动物：清掉全场该种
  - 配直线光或炸弹：全场该种全部变成对应特效，再一起引爆
  - 两只彩虹相撞：全屏清空
- 直线光和炸弹仍是原动物，必须被同类三连带上才会引爆，拿别的动物去换会原样弹回、不扣步数
- 20 关，目标分五类：分数、收集指定动物、清冰块、连锁次数、造特效个数

## 星级与结算

过关时按剩余步数评五档：

| 剩余占比 | 星级 | 评语 |
| --- | --- | --- |
| 0 ~ 15% | ★☆☆☆☆ | 及格 |
| 15% ~ 30% | ★★☆☆☆ | 良好 |
| 30% ~ 42% | ★★★☆☆ | 不错 |
| 42% ~ 55% | ★★★★☆ | 很棒 |
| 55% 以上 | ★★★★★ | 优秀（红旗评定） |

剩余步数每步折算 **100 分**，结算时逐补入总分。

进度存在程序同目录的 `save.txt`（解锁关卡 + 各关历史最高星级）。

## 调试参数

```
动物消消乐.exe --test        20 关自动对局，输出通过率
动物消消乐.exe --rule        规则断言（炸弹范围、直线方向、彩虹、拦截逻辑）
动物消消乐.exe --grind 2 60  反复跑第 2 关 60 局，输出通过率与关键指标
动物消消乐.exe --demo        只渲染一帧，用于检查排版
```

## 实现说明

- 渲染：ANSI 256 色背景 + 字母代表动物，`[A]` 表示有冰，选中格子反显；启动时把控制台切到 UTF-8 并开启 VT 转义
- 无动画，用整屏重绘加短暂停顿表现消除与掉落
- 需要 Windows 10/11 的 cmd 或 Windows Terminal

## 版本二：网页版（`web/index.html`）

单文件 HTML，双击即可在浏览器里玩，手机浏览器也能直接打开，不需要服务器、不需要联网。

- 直接打开 `web/index.html`
- 或在仓库 Settings → Pages 里把 `main` 分支的 `/web` 设为站点根目录，即可得到在线地址

### 玩法差异

网页版比 C 版多了这些内容：

| 内容 | 说明 |
| --- | --- |
| 多目标任务 | 越往后一关要同时满足 2~3 个条件（分数、收集、冰块、连消、特效、星星） |
| ⭐ 星星 | 棋盘上的发光星星，消掉所在格子即可收走，部分关卡要求收满若干颗 |
| 📦 箱子 | 盖住动物，不能交换也消不掉，需相邻消除两次才能砸开 |
| 组合技 | 直线+直线＝十字爆破；直线+炸弹＝十字宽带；炸弹+炸弹＝5×5 大爆炸；彩虹+彩虹＝全屏清空 |
| 道具 | 每关各 1 次：🔨 锤子、🔄 洗牌、➕ 加 5 步 |
| 动物轮换 | 每关启用 5~6 种动物，按关卡区间轮换，收集目标动物必定在场 |
| 星级 | 五档评定，剩余步数每步折算 100 分 |

进度保存在浏览器本地（localStorage），换设备或清缓存会重来。
